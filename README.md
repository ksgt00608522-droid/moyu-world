# 魔鱼世界（Moyu World）

一个复古网页文字打怪 RPG，为"摸鱼"而生——打开就能玩，关掉随时走。
纯本地运行，**零 AI 调用、零外部网络请求**，双击即玩，不装任何环境。

## 这是什么

文字 + 地图格子的摸鱼小游戏：你在大厅醒来，大厅四面墙上各有一扇门。可以走路、进门、跟人说话、接交任务、捡东西、学法术，身上会挂上各种正面/负面状态。

## 玩法现状（框架搭建中）

能做的：

- **地图探索**：多房间、门、移动（方向键 / WASD / 点格子）
- **NPC 与任务**：对话、接受 / 交付任务（走路、收集等目标）
- **物品与背包**：物品详情、钱袋、笔记本
- **技能与状态**：主动法术 + 被动技能、按步 / 按条件计时的正负面状态
- **事件点**：泉水、可捡物、机关等
- **存档**：本地存储 + 绑定磁盘文件（清缓存不丢）+ 导入 / 导出

还没定（见 `docs/设定/99-待定问题.md` 的 A 组）：

- 战斗、死亡、血量归零的后果
- 四扇门后面的真实内容
- 有没有终点 / 单局时长 / 平衡目标

## 运行

**开发**：双击 `index.html`（多文件，`file://` 直接跑，改完刷新即可）

**交付**：

```bash
node tools/build.mjs
```

产物 `dist/魔鱼世界.html` 是内联后的**单个 HTML**，双击即玩，压缩包或微信直发都可以。零依赖：无 npm、无 `node_modules`、无构建链。

## 验证（交付前必跑）

```bash
node tools/validate.mjs                                 # 校验素材数据
node tools/probe.mjs "file:///D:/魔鱼世界/index.html" tools/smoke.js   # 开发版冒烟
node tools/mutate.mjs                                   # 反向验证（故意改坏规则确认拦得住）
node tools/build.mjs
node tools/probe.mjs "file:///D:/魔鱼世界/dist/魔鱼世界.html" tools/smoke.js  # 产物复验
```

## 技术约束（要点）

`file://` 下无法用 ES Module、无法 `fetch` 本地 `.json`，所以：

- 全部走普通 `<script>` + 全局命名空间 `G`
- 数据写成 `G.data.x = [...]` 形式的 `.js`（内部仍是严格 JSON）
- 全程 UTF-8 无 BOM
- 依赖方向严格单向、不允许成环；逻辑与表现分离

完整约定见 `docs/设定/08-技术约束.md`。
